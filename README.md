# 🌍 Rutas del Mundo: Guía de Viajes Curiosos

¡Bienvenido a **Rutas del Mundo**! Esta es una plataforma interactiva diseñada para viajeros que buscan descubrir los rincones más insólitos y fascinantes de cada continente.

## 🚀 Demo en Vivo
Puedes ver el proyecto funcionando aquí: 
👉 https://andres-alma17.github.io/proyecto-html/

## 🛠️ Tecnologías Utilizadas
* **HTML5**: Estructura semántica de las 10 páginas del sitio.
* **CSS3**: Diseño personalizado, degradados, animaciones y diseño responsivo.
* **XML**: Generación de un Sitemap optimizado para motores de búsqueda.

## 🌟 Características Principales
* **Navegación Intuitiva**: Menú desplegable organizado por continentes y secciones temáticas.
* **Diseño Visual**: Slider infinito con destinos destacados y tarjetas de destino con efectos de animación.
* **Secciones Especializadas**: Galería de fotos, consejos para viajeros y una sección de gastronomía internacional.
* **Interactividad**: Formulario de contacto funcional y diseño adaptado a móviles.

## 📁 Estructura del Proyecto
* `/img`: Almacén de recursos visuales y mapas.
* `index.html`: Puerta de entrada con slider y estadísticas.
* `sitemap.xml`: Mapa del sitio para indexación.
* `estilos_proyecto.css`: Hoja de estilos centralizada.
